# Visuels à fournir

Dépose ici les fichiers portant exactement ces noms, puis renseigne le
chemin correspondant dans `src/data.js` (objet `MEDIA`, en haut du
fichier) — remplace le `null` par ex. `"/images/hero.jpg"`.

Tant qu'un visuel n'est pas fourni, un espace réservé (cadre rouge en
pointillés) s'affiche automatiquement à sa place : le site reste
utilisable sans aucune image.

## Portrait

- `hero.jpg` — photo de Randolphe, format portrait (hero de l'accueil)

## Parcours (une image d'ambiance par étape)

- `origines.jpg` — village de Hounviguè
- `formation.jpg` — ENSET Lokossa (ou Collège de l'Espoir, Comè)
- `diploma.jpg` — scan/photo du BAPET ou de l'attestation
- `situation.jpg` — EMTP Lokossa
- `experiences.jpg` — CHD de Lokossa ou Leader Électronique (Comè)
- `certifications.jpg` — session de formation / remise d'attestation

## Projets (`public/images/projects/`)

- `projects/capsule-verte.jpg`
- `projects/ficc-africa.jpg`
- `projects/fbtae.jpg`
- `projects/capsules-enset.jpg`

## Traitement recommandé avant import

Les images sont automatiquement passées en N&B/désaturé et encadrées
en rouge par le site (`Figure` dans `src/components/Figure.jsx`) — pas
besoin de les retoucher toi-même, un fichier couleur standard suffit.
